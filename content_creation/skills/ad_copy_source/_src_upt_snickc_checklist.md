# SNICK.C 6 元素 Checklist

> Skill 内置文件 · Portable · 不依赖外部
> 用途：`/ad-copywriter` skill 每次跑必读 + 每条变体输出前自检
> v1 · 2026-06-24

---

## 6 元素定义 + 在 long-form 文案里的分布

| 字母 | 全称 | 含义 | 在 long-form 里通常出现的段 | 表达形式 |
|:--|:--|:--|:--|:--|
| **S** | Solution | 直接提解决方案 / 结果 | 段 3-4（介绍产品/课程/服务）| "这才是真正的解决方案" / "找 [品牌] 就完全不用担心" / ✅ bullet list |
| **N** | Numbers | 用数字具象化 | 散落（痛点段 / 导师段 / 结果段）| 金额（RM）/ 时间轴（年/月）/ 人数（学员）/ 百分比（折扣、回报率）/ 倍数 |
| **I** | Issue | 描写最痛的痛点（重大问题）| 段 1-2（Hook 后的问题深化）| ❌ bullet list / 故事化反问 / 对比结构 |
| **C** | Certified Proof | 提供认证 / 背书（KKM / Halal / 行业证书）| 段 4-5（导师/公司介绍段）| 🏆 资历列表 / 学员数 / 政府认证（KKM/SGS/SIRIM/GMP/MOTAC）|
| **K** | Knowledge | 专业知识 / 使用方式（保健品 / 健康类等专业领域尤其重要）| Body 段（段 3）| "你会学到："+ 📌 5 个核心点 / STEP 1-5 / "为什么..." 科学说明 |
| **.C** | **Scarcity + CTA**（两个都必须有）| 紧迫感 + 明确行动指令 | 段 5-6（紧迫感段 + 最后段）| "限时/限名额/先到先得" **AND** WhatsApp/Link/电话/报名 |

⚠️ **.C 是 Scarcity AND CTA 两个都要塞**（不是二选一）。Self-check 时必须 confirm 两条都在。

---

## 融入式 vs 标签式

**禁止** 在文案里直接打 `[S]` `[N]` `[I]` 这种 label。SNICK.C 6 元素必须**自然融入** 6 段文案中，让 reader 看不出来在跑 checklist。

例：
- ❌ `[S] 解决方案：找我们 [I] 解决你的痛点`
- ✅ `找我们就对了！[品牌] 已经帮 3000+ 老板把这种烦恼变成历史`

---

## Self-check 流程（每条变体输出前必跑）

每写完一条变体，按以下顺序逐项确认：

```
[ ] S - Solution 元素：文案里能看到「找我们/这个产品/这套方法」的解决方案 mention 吗？
[ ] N - Numbers 元素：至少 1 个具体数字（RM 金额 / 年限 / 人数 / 百分比 / 倍数）？
[ ] I - Issue 元素：痛点段是否清楚描写了用户的痛？（❌ bullet 或叙事都行）
[ ] C - Certified Proof 元素：资历 / 认证 / 案例数 / 学员数 / 奖项 至少 1 项？
[ ] K - Knowledge 元素：教育性内容（STEP / 方法 / 科学说明 / FAQ）至少 1 段？
[ ] .C-1 - Scarcity 元素：紧迫感语句（限时 / 限名额 / 先到先得 / 数量有限）？
[ ] .C-2 - CTA 元素：明确行动指令（WhatsApp / 点链接 / 报名 / DM / 电话）？
```

**任何一项缺失** → 重写该条变体补足，**不放过**。

## SNICK.C 在 6 段骨架里的对应（cross-ref `framework.md`）

```
段 1: Hook
段 2: ❌ Pain bullet list           ← Issue (I) 主要在这里
段 3: 转折 + ✅ Solution + 📌 STEP   ← Solution (S) + Knowledge (K) 在这里
段 4: 权威背书 / 🏆 资历             ← Certified Proof (C) 在这里
段 5: 🔥 紧迫 + 限时优惠             ← Scarcity (.C-1) 在这里
段 6: 📲 CTA + 链接 + #hashtag      ← CTA (.C-2) 在这里
            ↓
Numbers (N) 散落各段（金额 / 人数 / 时间 / 百分比 / 倍数）
```

## 行业 SNICK.C 强调差异

不同行业 6 元素重点不同（参考用，不必死守）：

| 行业 | 最强元素 | 次强元素 |
|:--|:--|:--|
| 课程 / 研讨会 | Certified Proof（导师资历）| Knowledge（STEP）|
| 保健品 / 健康 | Knowledge（成分/使用方式）+ Certified Proof（KKM/Halal）| Issue（症状）|
| 房产 / 投资 | Numbers（数字驱动）| Solution（结果）|
| 服务（财务/装修）| Certified Proof（年限/案例）| Solution（流程）|
| 美食 / 产品 | Numbers（价格/优惠）| Scarcity（限时）|
| B2B 融资 | Certified Proof（银行资历）| Knowledge（流程）|

skill 写文案时按 Client MD 行业 priori 这 2 个元素的展开篇幅。
