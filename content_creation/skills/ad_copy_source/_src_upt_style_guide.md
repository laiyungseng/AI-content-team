# Style Guide · 马来西亚中文市场 Rojak 风格

> Skill 内置文件 · Portable · 不依赖外部
> 用途：`/ad-copywriter` skill 每次跑必读
> 风格基准提炼自 [owner] 校准的 3 sample + 40 sample 框架分析
> v1 · 2026-06-24

---

## 5 条 Rojak 拿捏铁则（核心红线）

### 1. 英文用在 noun + adj，动词短语用中文

✅ **可以用英文**：
- Noun：customer, follower, course, post, RM, boost, inbox, client, project, ROI, CPM, FB, IG, deadline, order, tool, team, sales, copy（仅业内术语，文案内文用「文案」）
- Adj：outdated, professional, fresh, limited, transparent, customized

❌ **不要用英文动词短语**：
- "wasting time" → 写「浪费时间」
- "what for" → 写「为了什么」
- "you know" → 写「你知道吗」
- "stop it" → 写「别这样」

理由：马来西亚中文市场广告里中英混用是自然的，但**动词** / **副词** / **形容词短语** 用中文才不会变成 SG-style Singlish 感。

---

### 2. 敢用马来西亚中文市场口语标记词

**核心 particle 词**（高频）：
- 「罢了」（≈ 而已 / nia）— 关键标记词
- 「你都不知道」
- 「想都想不到」
- 「酱」（这样，KL 华人口语）
- 「讲真的」
- 「根本」
- 「才是」
- 「完全」

**Bahasa Pasar / Manglish**（视客户行业用，餐饮 / 美容用得多，B2B 用得少）：
- 「nah」「geng」「sibeh」「ngam」「confirm」「jio」「kaki」「zap」

**语气助词**（要节制，不能堆砌）：
- 「lah」「lor」「hor」「leh」— **每条文案至多 2-3 个**，过多变 over

⚠️ [owner] 校准 case：「再 post 也是 wasting time」← over（wasting time 是英文动词短语）；改成「再 post 也是浪费时间」← ngam

---

### 3. 三段节奏：反问 / 断定 / 行动建议

文案的句式节奏应该有起伏，不要堆长句。常见三段：

```
[反问句] 让 reader 自动补全答案
↓
[断定句] 告诉 reader 真相 / 结论 + 感叹号
↓
[行动建议] 给 reader 下一步
```

**配感叹号 + 问号** 制造情绪起伏（不要每句都句号）。

[owner] sample 例：
> 你 post 了三个月 follower 还是那几个？方法早就 outdated 了！再 post 也是浪费时间。

---

### 4. 句长中等，不砍太短也不堆长句

参考 [owner] 校准 sample 长度：每句 12-25 字为主，偶尔 30+ 字带细节。

**禁止**：单句超 50 字（reader 在 FB 滚动时读不下去）。

---

### 5. 文案 / 想 类核心词用中文

⚠️ **特别注意**：「copy」「write copy」「想 copy」这种英文在马来西亚中文市场广告口语**不自然**。

✅ 写「文案」「写文案」「想文案」
❌ 写「copy」「写 copy」「想 copy」

虽然行业内 copywriter 一词用英文 OK，但**文案产物本身** 永远用「文案」中文。

[owner] 校准 case：「以后不用再坐着想 copy 了」← 不自然；改成「以后不用再自己想文案了」← ngam

## Emoji 规则

### Default ON（long-form FB 客户广告）

40 sample 拆解显示 emoji 是**marker 系统的一部分**（不是装饰）：

- 🔥 = 重点强调 / 爆点 / 限时优惠（85% sample 用）
- ✅ = 解决方案列表（72%）
- ❌ = 痛点标记（68%）
- 📌 = 学习步骤 / 知识点（65%）
- 🏆 = 资历背书（60%）
- 📲 = 联系方式（52%）
- 😱😮 = 震撼（50%）
- 👉 = 指向引导（48%）
- 📍 = 地址（45%）
- 💡 = 洞察转折（45%）
- ✨ = 特别亮点（42%）
- 🎁 = 赠送优惠（38%）
- 💰 = 金钱成本（35%）
- 💚💜🩷 = 品牌色 / 多项目列表（25%）

**必用位置**：
- Hook 段末（情绪标记）
- Marker bullet 前（❌ ✅ 📌）
- CTA 前（🔥 紧迫）
- 联系方式段（📲 📍）

**禁用位置**：
- 正文段中间（emoji 太密会乱）
- Hashtag 段（hashtag 自带 # 已是视觉 marker）

### 行业 emoji 选择

| 行业 | 主用 emoji |
|:--|:--|
| 健康 / 中医 / 美容 | 💚 💜 🧘 ✨ 🌸 |
| 房产 | 🏠 🏢 🔑 📈 |
| 餐饮 | 🍣 🦀 🍱 🔥 |
| 教育 / 课程 | 📚 ✏️ 🎓 📝 |
| 财务 / 融资 | 💰 💵 🏦 📊 |
| 装修 | 🔨 🛠️ 🏗️ |

### Override：No-emoji

User 可以启动时说「不要 emoji」/「no emoji」/「干净版」→ 全部 emoji 关掉（保留 bullet 用字母如 A/B/C 替代 marker）。

## 长度规则

### Default：long-form 中等长度

参考 40 sample 行业长度区间（写在 `framework.md`）：
- 课程 / 研讨会：1200-1600 字
- 产品销售：1200-1800 字
- 房产投资：1000-1500 字
- 房屋装修：1000-1200 字
- 财务 / 融资：900-1300 字
- 旅游：800-1200 字
- 医疗 / 美容：600-1000 字
- 美食餐饮：400-800 字

User 没指定行业 → 按 Client MD 行业字段判断；都没 → 默认中等 800-1200 字。

### Override：短 / 长

User 可以启动说：
- 「短版 / short」→ 200-400 字（FB carousel 单页 / WA broadcast）
- 「中版」→ 600-1000 字
- 「长版 / long」→ 1500+ 字（研讨会招生 / 高客单价产品）

---

## 段落分隔符

40 sample 用 `.`（单独一行的句号）做段落分隔，不是空行。这是马来西亚中文市场 FB 广告特殊排版习惯。

```
段 1 第一行
段 1 第二行
.
段 2 第一行
.
段 3 第一行
```

少数 sample 用 `---` 或 `——————` 做大段分隔（如 Hook 段到 CTA 段之间）。

skill 出文案默认用 `.` 单行分隔。

---

## CTA 段不带 icon emoji（既定规则）

⚠️ CTA bar 永远不带 ✉️ / 📩 / 📞 / 📲 这类 icon emoji 在「按钮文字」前。

✅ `按 Send Message 找我们下单`
❌ `📩 按 Send Message 找我们下单`

但**联系方式段**（电话 / 地址 / WA）emoji **可以**（实际 sample 都有）：
- ✅ `📲 𝐏𝐡𝐨𝐧𝐞 𝐍𝐨. 012-xxx-xxxx`
- ✅ `📍 地址：xxx`

区分关键：**按钮文字前** = 不加 emoji icon；**信息行前** = 可以加 emoji 当 visual marker。

---

## 终极输出 cleanliness 规则

每条变体输出给 user 时 = **final ready-to-copy-paste**：

- ✅ 干净文案，可直接 paste 到 FB 发布
- ❌ 不带 dev label（「变体 1：」是允许的 metadata；但文案内不要带 `[hook: 痛点反问]` 这种 dev 标注）
- ❌ 不带内部 ref 数字（「这里参考 sample 12 的 hook」之类）
- ❌ Hashtag 在最后段，跟正文用 `.` 分隔
