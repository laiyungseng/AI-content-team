# Carousel 内容类型 brainstorm 清单

这份是**写内容时的灵感库**，不是 skill 的设计模板。同一个内容类型可以套不同 design layout。

按使用频率排：

## 🔥 高频可复用（最常用）

| 内容类型 | 典型 layout | 例子 |
|---------|------------|------|
| 教学 How-to | cover + numbered-step + cta | "3 步骤用 Claude Code 跑 Meta Ads" |
| 金句海报 | big-statement | "不是技术不够好，是定位不够准" |
| 错误避坑 | cover + comparison ×N + cta | "跑 AI 营销最常踩的 5 个坑" |
| 工具推荐 | cover + checklist + cta | "2026 年我每天用的 7 个 AI 工具" |
| 案例拆解 | cover + title-body + stat-cards + cta | "[client] 月入 6 位数怎么做到的" |
| 客户见证 | cover + testimonial ×N + cta | "[client] 学员上完课后说..." |
| 对比 vs | cover + comparison + cta | "Canva vs HTML 出轮播图" |
| 数据 / 数字 | cover + stat-cards + cta | "我们用 30 天测了 47 个 AI 工具" |

## 💡 中频高价值（适合做品牌内容）

| 内容类型 | 典型 layout |
|---------|------------|
| 思维框架 / 公式 | cover + numbered-step / quote |
| Listicle 清单 | cover + checklist |
| Q&A / FAQ | cover + title-body ×N |
| 趋势盘点 | cover + stat-cards + numbered-step |
| Glossary 名词解释 | cover + title-body ×N |
| Mini Course 微课 | cover + numbered-step + checklist + cta |
| 资源汇总 | cover + checklist |
| 预告 / Reveal | cover + big-statement + cta |

## ✨ 低频杀手级（差异化爆款）

| 内容类型 | 典型 layout |
|---------|------------|
| Story / Journey 个人故事 | cover + title-body ×N + cta |
| Before / After 对比 | cover + image-caption ×2 + comparison + cta |
| 公开账本 / 透明化 | cover + stat-cards ×N + cta |
| 客户 Onboarding 包装 | cover + numbered-step + cta |
| Behind the scenes | cover + image-caption ×N |
| 节日 / 时事 hijack | big-statement + cta |
| 会议 / 活动小红书风 | cover + image-caption ×N + cta |
| 课程 Cliff Note | cover + quote + numbered-step + cta |

---

**用法**：写内容前翻这份，找最合适的内容类型 → 看典型 layout 推荐 → 跑 skill。
