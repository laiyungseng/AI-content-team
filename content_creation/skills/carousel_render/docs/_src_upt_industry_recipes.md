# 行业 → Carousel Sequence 推荐

按客户所在行业自动推 top 3 sequence，避免小白选择困难。

---

## 🚗 B2C 服务业（汽车 / 餐饮 / 健身 / 美容 / 医疗 / 婚礼 / 摄影 / 装修）

| 推荐 sequence | 为什么 |
|--------------|--------|
| **Before/After (5 张)** | 视觉冲击力最强，服务效果一图见效 |
| **客户见证 (3-5 张)** | 信任 build，社会证明 |
| **服务套餐 / 价格 (4-6 张)** | 转化导向，直接给方案 |

典型 layout 组合：cover → image-caption (before) → image-caption (after) → stat-cards (改善%) → cta

---

## 💼 B2B 专业服务（融资 / 律师 / 会计 / 保险 / agency / SaaS / 顾问）

| 推荐 sequence | 为什么 |
|--------------|--------|
| **思维框架 / 公式 (5-7 张)** | 专业感 + 教育，建立 thought leadership |
| **案例拆解 (7 张)** | 数据驱动，B2B 决策者爱看 |
| **错误避坑 (6 张)** | 高 save rate，受众痛点直击 |

典型 layout 组合：cover → quote → numbered-step → stat-cards → testimonial → cta

---

## 🛍️ 产品 / 电商（时尚 / 美妆 / 母婴 / 家居 / 食品 / D2C）

| 推荐 sequence | 为什么 |
|--------------|--------|
| **UGC 客户使用 (5-7 张)** | 真实感最强，转化高 |
| **产品 vs 产品 (4-5 张)** | 帮决策，痛点 vs 解决 |
| **使用场景 (5-6 张)** | 让买家自我代入 |

典型 layout 组合：cover → image-caption (UGC) ×3 → comparison → cta

---
