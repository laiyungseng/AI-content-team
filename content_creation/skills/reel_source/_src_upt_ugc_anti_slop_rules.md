# 全局风格 — 真人 UGC 反 slop 铁律

> **这段是马来西亚华人本地 UGC 广告的底线**。每一个 Shot 的「完整 Prompt（多参考 + 口型同步全中文版）」都要**逐字嵌入**这一块，位置在 `[参考素材]` 之后、`[Shot N — X 秒]` 之前。

---

## 铁律原文（直接嵌入 Seedance / Higgsfield prompt）

```
[全局风格 — 真人 UGC]
真人朋友视角第一人称短视频。手机原生拍摄，未经修饰，竖屏 9:16，手持自然抖动加呼吸感微晃，偶尔轻微对焦漂移。竖屏短视频抓拍美学，业余拍摄感，构图略微不完美。柔和自然环境光，无人工补光，真实肌肤纹理可见毛孔。绝对禁止：字幕、音乐、覆盖层、特效、调色、电影感、稳定器顺滑运镜、高清锐利度、专业运镜动作。
```

---

## 为什么要有这一块

Seedance / Higgsfield 等 video gen 模型默认会往**电影感 / 稳定器 / 广告腔**方向 drift。马来西亚华人本地广告要的是 **真实好友视角**（IG Reel / TikTok 素人质感），一旦模型自动上滤镜 + 顺滑运镜，观众第一秒就知道是广告，直接滑走。

反 slop 铁律的目标：
- **禁**：字幕、BGM、覆盖层、色彩滤镜、慢动作、电影感镜头、稳定器顺滑跟拍、专业运镜
- **要**：手机原生质感、手持自然抖、构图略偏、真皮肤毛孔、日常光线

---

## 若用户明确要电影感 / 品牌片风格怎么办

只有用户在 Step 4「本地化调性」明确说「我要电影感 / 品牌 TVC 风格 / 稳定器美学」时，才可以**换掉**这一块，改成对应的风格描述。默认情况下永远用真人 UGC 铁律。

---

## 变体（备用，只在用户明确指定时替换）

### 变体 A：办公室专业感 UGC
```
[全局风格 — 办公室专业 UGC]
办公室第一人称短视频。手机拍摄但相对稳定（桌面小三脚架感），竖屏 9:16，白天办公室自然光配少量顶灯，构图工整但保留手机质感。允许：轻微文字提示、极简 CapCut 数据标签。禁止：BGM、电影感调色、专业运镜、稳定器丝滑跟拍、后期特效。
```

### 变体 B：户外 Vlog 感 UGC
```
[全局风格 — 户外 Vlog UGC]
街头第一人称 vlog。手机手持，竖屏 9:16，室外自然光（可有阴影），行走中轻微晃动，环境音真实。允许：轻微跳切、口播中断补拍。禁止：BGM、电影感调色、稳定器、专业运镜、字幕。
```

## 使用检查清单

生成第 6 列「完整 Prompt」前，自查：

- [ ] `[全局风格 — 真人 UGC]` 块**完整**嵌入了（不是概括、不是摘要）
- [ ] 「绝对禁止」清单包含：字幕 / 音乐 / 覆盖层 / 特效 / 调色 / 电影感 / 稳定器 / 高清锐利 / 专业运镜
- [ ] 除非用户明确要求，没换成变体 A / B
- [ ] 每个 Shot 都嵌了这一段（不是只嵌 Shot 1）

任何一项 ❌ → 补齐再交付。
