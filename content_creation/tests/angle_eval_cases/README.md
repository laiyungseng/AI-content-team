# Angle evaluation cases

Three briefs that test [[angle_evaluation]]. Run `content_strategist` on each as a dry run (no project data written) and check the output against the case's "Must" list and the acceptance checks below. They use fictional businesses; the market and language are part of the test, not a default.

| Case | Tests |
|---|---|
| `eval_case_home_custom.md` | price war, trust, lead quality, filtering buyers who only compare prices |
| `eval_case_ai_course.md` | positioning a course as a system, not a tools class; no income claims |
| `eval_case_sme_financing.md` | regulated claims: still strong angles with no misleading promise |

## Acceptance checks
1. The output follows the [[content_strategy]] template, sections 1 to 15.
2. It includes buyer hesitation, the kill filter, rewritten angles and strict scoring (caps applied).
3. At least three concepts are producible this week.
4. Home custom: at least three usable concepts.
5. AI course: positioned as building a marketing system or AI marketing employee.
6. Financing: no guaranteed approval or misleading claim; assessment wording present.
7. No generic filler (see the detector in [[angle_evaluation]]).
8. Hooks have a named hook type from `shared/frameworks/hooks.md`.
