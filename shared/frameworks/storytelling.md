# Story Formats

Every format maps to a fixed story structure for the body of the script. Pick the format first, then write the body to its shape. This is a lookup file, so find the row that matches and work from it rather than reading the whole thing.

Formats split into two categories: educational (information delivered to the viewer or about something external) and storytelling (information delivered from the creator's first-person experience).

Never write a body freehand when a proven structure exists.

## 1. How to choose a format

The starting point decides the format. Ask what the raw material actually is:

- A topic, event or concept in the world → breakdown, explainer, reaction
- A result someone got → case study
- A problem the viewer has → problem and solution, common trap
- A skill or process → tutorial
- A set of options → listicle, comparison, ranking, levels
- A question → Q&A
- A personal experience → any storytelling format

If the user has firsthand experience and proof, storytelling formats usually beat educational ones, because the proof itself is the contrast. If they do not, an educational format is safer.

## 2. Educational formats

| Format | Starting point | Story structure |
|---|---|---|
| Breakdown / explainer | A topic, event or concept | Hook (sets up "what happened") → rapid context → core breakdown → so what / implication → CTA |
| Case study | An example of success | Case study hook → context on what they did → core breakdown → key insight → CTA |
| Problem and solution | A problem | Problem hook → problem agitation → core solution → implication → CTA |
| Common trap or mistake | A trap or mistake | Hook → trap agitation → trap reveal → introduce the correction → optional CTA |
| Tutorial | A skill or process | Education hook → establish the objective → step by step → optional implication → CTA |
| Listicle | A list | Hook → the list → optional implication → CTA |
| Scenario | A hypothetical | Scenario hook → scenario context and baseline → solution breakdown → optional implication → CTA |
| A vs B vs C comparison | A comparison | Hook → comparison criteria → break down and rank each option → CTA |
| Q&A | A question | Hook (often the question itself) → context on why it matters → the answer → optional takeaway → CTA |
| Ranking / rating / tier list | Options to compare | Ranking hook → establish the scale or scoring system → rapid ranking one by one → optional CTA |
| Levels | Options in ascending order | Hook → establish category and scale → level progression → CTA |
| Reaction | A base video to react to | Hook → let the original clip play → give the reaction or take → CTA |

## 3. Storytelling formats

These are more open-ended and flexible than educational formats, because the first-person experience carries them.

| Format | Story structure |
|---|---|
| Skit / humour | Hook → set up the scene → back and forth between characters → payoff → CTA |
| Hero's journey (first-person transformation) | Hook → call to adventure and context → struggle, obstacles, failures → transformation → after state → CTA |
| Personal learning / epiphany | Hook → desired result with proof shown early → before state → process to transformation → lessons and epiphanies → CTA |
| Day in the life | Hook → context and relatable chaos → daily routine → reflection → CTA |
| Personal update | Hook → context on the situation → the update → rationale for the decision → optional CTA |
| About me | Hook → context on normal life → epiphany or change moment → how it changed the path → CTA |
| Episodic series / social show | Hook → context for the episode → plot arc → resolution or cliffhanger → CTA |
| Challenge | Hook → context on the challenge → plot arc of completing it → resolution or cliffhanger → optional CTA |

## 4. What changes between them

Note the difference in where proof sits. Personal learning / epiphany leads with proof and the desired result before teaching anything. Hero's journey leads with the mistake or obstacle first and holds the result back. Both work, but they buy attention in opposite ways: one buys it with credibility, the other with tension.

Choose deliberately. If the audience does not know the creator, lead with proof. If they already trust the creator, tension holds better.
